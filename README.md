# Книги на слух

Плеер-книга для практики английского на слух: на экране русский текст, диктор читает
английский перевод уровня A2–B1, текущая фраза подсвечивается ровно тогда, когда звучит.

Открыть: страница `index.html` этого сайта (GitHub Pages). Работает на телефоне и компьютере,
без интернета — после кнопки «↓» у голоса в настройках; ставится на главный экран как приложение.

## Что внутри

| Путь | Что |
|---|---|
| `index.html`, `app/shelf.js` | Полка книг |
| `reader.html`, `app/*.js` | Плеер: подсветка фраз и слов, подсказки, эхо, повторы, голоса, тональность, словарь, вопросы |
| `sw.js`, `manifest.webmanifest` | Работа без интернета и установка на экран |
| `books/<книга>/book.json` | Текст, перевод фраза к фразе, подсказки к словам, вопросы |
| `books/<книга>/timings/<голос>.json` | Время каждой фразы и слова в звуке |
| `books/<книга>/audio/<голос>/chN.mp3` | Озвучка по главам |
